# Showcase video: shot list

Everything the addon does, grouped into **recording sessions by place**, so one trip covers many
features. In each session, keep the recorder running and play the Demo Hub buttons (`/cine demo`, or
Dev hub › Demo Commands) back to back, then cut them apart in editing.

**Before every session**
- Dev copy loaded (`CinematicDev.toc`), profile **Cinema** or your own showcase profile.
- Raise WoW's **UI Scale** for the settings shots so the text can be read on video.
- Demo Hub settings: countdown 3, *Hide the hub while running* on, *Captions* on for the carousels
  (tints, moods, DoF, cards, camera reel), off for the clean B-roll.
- Between takes: **Clean slate** (Recording helpers).
- Kill nameplates/chat spam you don't want: a quiet realm hour helps.

Legend: **[Hub]** = a Demo Hub button runs it on its own. **[Live]** = you have to do it in the game.
**[Fake]** = pretended by the hub, good enough for video.

## Can't be faked: plan for these

- **Real Flight Cam landing** needs a route you've flown before.
- **Weather** depends on the zone's weather at the time.
- **Heal Vision, ready checks, real rolls** need a group.
- **Quest Cam / Quest Vision** need a quest giver with a quest you haven't done (an alt is easiest).
- **Campfire / Camp Benefits** are Forever only.
- **Swing timer** is Classic only, **Cooldown Manager** is retail only: decide which client the
  video is on, or record both.
