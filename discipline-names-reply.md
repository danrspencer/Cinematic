Added this for you! Style, Unit Frames now has a Long names row. Pick First name and a name too long for its frame drops its last words instead of showing the dots, so Benediction Cumberbatch shows as Benediction. Before, the game cut the name at the frame's edge and added the dots, and there was no way to turn that off. A single long word loses its last letters, again with no dots. It works per frame too, using the frame tabs on that page. Enemy names in a fight are hidden from addons, so those can still show the dots. It will be in the next update. Hope that helps, please let me know if it doesn't.
