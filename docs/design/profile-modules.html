Profile Modules

One system, three layers. Modules hold settings for the pages and sections they name. Choices are what players pick in each area of their setup, and each choice is a list of modules. Profiles are a pick per area. The welcome window's levels each pick a profile.

Picking a choice swaps just that area's settings and leaves everything else alone. The choices and profiles all live in one file, ProfileChoices.lua, and the dev build's Module Editor changes them in the game. Everything below is drawn from the addon's real code, loaded outside the game.

Module Editor

Everything in ProfileChoices.lua and ProfileModules.lua, editable in the game. Your changes are kept (green) until you clear them, and a profile takes them when picked or reset. Export changes gives the Lua to paste back.

  • Profiles: each built-in's choice per area. Click a cell to pick another, + for modules of its own, Undo to go back to the code's.
  • Choices: each area's choices. Modules… ticks one in or out, and Try puts the choice on your live settings.
  • Modules: pick one to see every setting it changes and where (red means outside its scope), and edit its name, description and scope. Try it on applies it to your live settings. Take live settings rebuilds it from what you've set up in its pages. New from… makes a module from any page or section. Tested: on CDM, Take live settings rebuilds the CDM module with exactly the same 28 changes.
  • Run checks runs the same checks as /cine debug modules and CI.

The automated checks

lua5.1 Tools/offline/check.lua loads the real addon on both clients and both builds and checks it. CI runs it on every push, and in the game it's /cine debug modules or the editor's Run checks. It checks that:

  • ✓every module only changes settings inside its scope;
  • ✓no two modules of a profile change the same setting, and no setting is changed by the choices of two areas;
  • ✓every choice and profile names modules and choices that exist, and every module is used;
  • ✓no profile changed: every built-in still matches main's own code on both clients, all 6,696 frame rows each included;
  • ✓picking each Customize choice lights only that choice and leaves the other areas as they were.
